
# Clinic Booking Website

A responsive clinic appointment booking website
built using HTML, CSS, and JavaScript.

## Features
- Book appointments
- Select doctors and appointment dates
- Edit existing appointments
- Delete appointments
- Prevent booking past dates
- Save appointments using localStorage

## Technologies
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Live Demo
https://asdhotmafaz2.github.io/clinic-booking-website/

## Note
This is a front-end educational project.
Appointments are stored locally in the browser.
No backend database is connected.
